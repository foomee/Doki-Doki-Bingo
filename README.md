# ①課題名
ドキドキビンゴ

## ②課題内容（どんな作品か）
じゃんけん→ランダムなもの→ビンゴという連想から、ビンゴアプリを作りました。

## ③アプリのデプロイURL
https://foomee.github.io/Doki-Doki-Bingo/

## ④アプリのログイン用IDまたはPassword（ある場合）
今回はありません。

## ⑤工夫した点・こだわった点
・見た目部分は簡素なものにして、JS部分に時間をかけました。
・左側の表や右側の抽選済み数字はHTMLには直接記述せず、JavaScriptで生成しています。

## ⑥難しかった点・次回トライしたいこと（又は機能）
DOM要素の生成・追加というのをやっていて、これについて理解するのが難しく、とりあえずコードを日本語化できるように努めました。
その翻訳した日本語の文章の意味はわかっていないです。

「ドキドキビンゴ」という名前になっていますが、本来はこのアプリにドキドキ要素を追加したかったのです。
ですが、それは次の課題に回そうと思います。

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
制作途中で他にも面白そうなアイディアが思い浮かび、そちらを作りたくなってしまったので、少し中途半端になってしまった感じがあります。
